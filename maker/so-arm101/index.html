      1
Miniforge 설치하기

      

        
Miniforge는 파이썬과 여러 프로그램을 깔끔하게 관리해 주는 도구예요. LeRobot 공식 설치 가이드가 권장하는 방법이에요.

        
    
          
  1. 브라우저에서 github.com/conda-forge/miniforge에 접속해요.
    2. 
          
  2. 아래쪽 다운로드 표에서 Windows / x86_64 줄의 Miniforge3-Windows-x86_64.exe를 내려받아요.
    3. 
          
  3. 설치 파일을 실행해 Next → I Agree → Just Me를 고르고, 설치 위치 경로에 한글이나 띄어쓰기가 있으면 C:\miniforge3로 바꾼 뒤 Install → Finish.
    4. 
          
  4. 윈도우 키를 누르고 miniforge를 입력해 Miniforge Prompt를 실행해요.
    5. 
        

        
까만 창 맨 앞에 (base)가 보이면 성공이에요.

        
중요 앞으로 모든 명령어는 이 Miniforge Prompt 창에 입력해요. 일반 명령 프롬프트(cmd)나 PowerShell에서는 동작하지 않을 수 있어요.

      

    


    

      2
가상환경 만들기

      

        
가상환경은 LeRobot 전용 작업 공간이에요. 다른 파이썬 프로그램과 섞이지 않게 해 줘요. LeRobot은 Python 3.12가 필요해요.

        
① 가상환경 만들기 (1~3분)

        
conda create -y -n lerobot python=3.12

        
② 가상환경 들어가기

        
conda activate lerobot

        
맨 앞의 (base)가 (lerobot)으로 바뀌면 성공이에요.

        
③ 영상 처리 프로그램(ffmpeg) 설치

        
conda install -y ffmpeg -c conda-forge

        
매번 기억하기 Miniforge Prompt를 새로 열 때마다 conda activate lerobot을 먼저 입력해요. 앞에 (lerobot)이 없으면 lerobot- 명령어를 찾을 수 없다는 오류가 나요.

      

    


    

      3
LeRobot 설치하기

      

        
SO-101의 모터(Feetech STS3215)와 통신하려면 LeRobot 본체와 함께 feetech 옵션을 설치해요. Git 같은 추가 프로그램은 필요 없어요.

        
① 설치 (5~15분)

        
pip install "lerobot[feetech]"

        
글자가 많이 지나가도 괜찮아요. 마지막 줄에 Successfully installed ...가 보이면 끝이에요.

        
② 설치 확인

        
lerobot-find-port --help

        
사용법 안내 글이 나오면 성공이에요. "내부 또는 외부 명령이 아닙니다"가 나오면 앞에 (lerobot)이 있는지 확인하세요.

        
선생님용 소스 코드를 직접 고쳐 볼 학생은 Git을 설치한 뒤 git clone https://github.com/huggingface/lerobot.git → cd lerobot → pip install -e ".[feetech]"로 설치해도 돼요.

      

    


    

      4
로봇 연결하고 COM 포트 찾기

      

        
① 연결하기

        
    
          
  1. 두 팔을 책상에 클램프로 단단히 고정해요.
    2. 
          
  2. 각 팔의 컨트롤러 보드에 전원 어댑터를 꽂아요. 팔로워암 12V, 리더암 5V. 꽂기 전에 어댑터의 OUTPUT 전압을 확인해요.
    3. 
          
  3. 두 보드를 USB 케이블로 노트북 본체에 연결해요. (USB 허브는 피해요.)
    4. 
        

        
② 드라이버 확인

        
    
          
  1. 윈도우 키 + X → 장치 관리자를 열고 포트(COM & LPT)를 펼쳐요.
    2. 
          
  2. USB-SERIAL CH340 (COM3)이나 USB 직렬 장치 (COM4) 같은 항목이 2개 보이면 정상이에요.
    3. 
          
  3. 노란 느낌표가 있거나 기타 장치에만 보이면 드라이버가 없는 거예요. 선생님께 알려 주세요. (보드 칩에 맞는 CH340/CH343 또는 CP210x 드라이버를 설치해요.)
    4. 
        

        
③ 어느 팔이 어느 포트인지 찾기

        
lerobot-find-port

        
    
          
  1. 연결된 포트 목록이 나와요. 예: ['COM3', 'COM4']
    2. 
          
  2. Remove the USB cable ... and press Enter가 나오면 리더암 USB만 뽑고 Enter.
    3. 
          
  3. The port of this MotorsBus is COM3처럼 나온 번호가 리더암 포트예요. USB를 다시 꽂아요.
    4. 
          
  4. 한 번 더 실행해서 이번엔 팔로워암 USB만 뽑아 팔로워암 포트를 찾아요.
    5. 
          
  5. 찾은 번호를 위쪽 내 로봇 정보 칸에 적어요.
    6. 
        

        
주의 USB를 다른 구멍에 꽂거나 보드를 바꾸면 COM 번호가 바뀔 수 있어요. 매번 같은 구멍에 같은 팔을 꽂고, 바뀌었다 싶으면 이 단계를 다시 해요.

      

    


    

      5
모터 ID 설정하기 (팔마다 처음 한 번)

      

        
팔 하나에는 모터 6개가 케이블로 줄줄이 이어져 있어요(데이지 체인). 보드가 모터를 구분하려면 모터마다 1~6번의 서로 다른 번호(ID)가 있어야 해요. 새 모터는 모두 1번이라, 이 단계를 건너뛰면 캘리브레이션에서 Missing motor IDs 오류가 나요. 번호는 모터 안(EEPROM)에 저장되니 한 번만 하면 돼요.

        
이미 됐는지 확인 6단계 명령어를 먼저 실행해 오류 없이 Move ... to the middle 안내가 나오면 이 단계는 건너뛰어요.

        
① 모터를 하나씩 떼어 놓기

        
    
          
  1. 전원 어댑터와 USB는 연결해 둬요.
    2. 
          
  2. 보드와 1번 모터 사이, 모터와 모터 사이의 3핀 케이블을 모두 뽑아요. 모터마다 소켓이 2개라 양쪽을 다 확인해요.
    3. 
          
  3. 보드에 3핀 케이블 하나를 꽂아 두고, 반대쪽 끝을 모터에 하나씩 옮겨 꽂아요.
    4. 
        

        
② 명령어 실행

        
팔로워암

        

        
③ 안내에 따라 모터 하나씩 연결

        
Connect the controller board to the 'gripper' motor only and press enter.처럼 이름이 나오면 보드 케이블을 그 모터 하나에만 꽂고 Enter. 'gripper' motor id set to 6이 나오면 다음 모터로 옮겨요.

        

          
순서화면 이름관절 위치설정되는 ID

          
            
1gripper집게6

            
2wrist_roll손목 회전5

            
3wrist_flex손목 굽힘4

            
4elbow_flex팔꿈치3

            
5shoulder_lift어깨2

            
6shoulder_pan받침 회전1

          
        

        
Enter 전에 매번 보드에 연결된 모터가 딱 하나인지, 그 모터의 다른 소켓이 비어 있는지, 전원 케이블이 빠지지 않았는지 확인해요. 첫 모터(gripper)부터 못 찾으면 전원 LED, 점퍼(B 채널), 케이블을 보고, 그래도 안 되면 보드를 바꿔 시험해요.

        
④ 케이블 원래대로 잇기

        
보드 → 1번(받침) → 2번(어깨) → 3번(팔꿈치) → 4번(손목 굽힘) → 5번(손목 회전) → 6번(그리퍼) 순서로 다시 이어요. 조립 3D의 8단계에서 케이블 길을 볼 수 있어요.

        
⑤ 리더암도 똑같이

        
리더암은 명령어만 달라요.

      6
팔로워암 캘리브레이션

      

        
캘리브레이션은 각 관절이 어디까지 움직이는지 로봇에게 알려 주는 과정이에요. 이걸 해야 두 팔이 같은 자세일 때 같은 값을 가져서 똑같이 움직여요. 팔마다 처음 한 번만 해요. 시뮬레이션의 캘리브레이션 연습으로 먼저 해 봐도 좋아요.

        
① 명령어 입력

        

        
② 중간 자세 만들기

        
Move ... to the middle of its range of motion and press ENTER가 나오면 모든 관절을 움직일 수 있는 범위의 한가운데에 두고, 그리퍼는 반쯤 벌린 채 Enter.

        
③ 관절 전체 범위 움직이기

        
MIN / POS / MAX 숫자 표가 나오면 관절을 하나씩 한쪽 끝에서 반대쪽 끝까지 천천히 움직여요. 순서: 받침 회전 → 어깨 → 팔꿈치 → 손목 굽힘 → 손목 회전 → 그리퍼. 끝에 닿으면 억지로 더 밀지 않아요. 다 했으면 Enter, Calibration saved to ...가 나오면 성공이에요.

        
표에 관절이 5개만 보여요 빠진 것이 wrist_roll(손목 회전)이면 정상이에요. 버전에 따라 손목 회전은 한 바퀴 도는 관절로 보고 전체 범위를 자동으로 넣어요. 다른 관절이 빠졌다면 선생님께 알려요.

        
2인 1조 팁 한 명은 팔을 움직이고, 한 명은 화면의 MIN/MAX가 크게 벌어지는지 확인해요. 숫자가 거의 안 바뀌는 관절은 다시 끝까지 움직여요.

      

    


    

      7
리더암 캘리브레이션

      

        
방법은 팔로워암과 같고, 명령어의 robot이 teleop으로 바뀌어요. 리더암은 조종기(teleoperator)이기 때문이에요.

        

        
  1. 모든 관절을 가운데에 두고 Enter
  2. 관절을 하나씩 끝에서 끝까지 천천히
  3. Enter → Calibration saved to ... 확인

        

          
팔명령어 앞부분종류(type)

          
            
팔로워암--robot.so101_follower

            
리더암--teleop.so101_leader

          
        

      

    


    

      8
리더암과 팔로워암 연동하기

      

        
① 시작 전 안전 확인

        
    
          
  • 팔로워암 주변(팔 길이 안쪽)에 사람, 물건, 손이 없다.
    • 
          
  • 리더암을 팔로워암과 비슷한 자세로 맞춰 두었다. (시작하는 순간 팔로워암이 리더암 자세로 빠르게 움직여요.)
    • 
        

        
② 실행

        

        
오류 없이 실행되면 연동이 시작된 거예요. 리더암을 천천히 움직여 팔로워암이 따라오는지 봐요. 관절 값을 화면에서 보고 싶으면 명령어 끝에 --display_data=true를 붙여요 (버전에 따라 별도 창이 열려요).

        
③ 종료

        
    
          
  1. 팔로워암을 한 손으로 받쳐요. 종료하면 힘이 풀려 팔이 처질 수 있어요.
    2. 
          
  2. Miniforge Prompt 창을 클릭하고 Ctrl + C.
    3. 
          
  3. 팔로워암을 쉬는 자세로 내려놓고, 다 쓰면 USB와 전원을 뽑아요.
    4. 
        

        
성공 기준 리더암의 6개 관절(그리퍼 포함)을 각각 움직였을 때 팔로워암의 같은 관절이 같은 방향으로 따라오면 완료예요. 한 관절만 반대로 가거나 끝까지 안 가면 그 팔의 캘리브레이션을 다시 해요.

        
다음 시간에 다시 켤 때

        
    
          
  1. 두 팔 고정 → 전원 어댑터 → USB 연결 (지난번과 같은 구멍)
    2. 
          
  2. Miniforge Prompt에서 conda activate lerobot
    3. 
          
  3. 위의 lerobot-teleoperate ... 명령어를 같은 이름(id)으로 실행
    4. 
        

        
이름(id)을 바꾸면 저장된 캘리브레이션을 못 찾아요. 캘리브레이션 파일은 C:\Users\(사용자 이름)\.cache\huggingface\lerobot\calibration 폴더에 이름별로 저장돼요.

      

    

  







  

    

      Part 4
      
문제 해결과 안전 수칙

      
실제 수업에서 생겼던 문제들이에요. 증상이 보이면 위에서부터 차례로 확인해요.

    

  

  

    
증상원인해결 방법

    
      
lerobot-...은(는) 내부 또는 외부 명령이 아닙니다가상환경에 안 들어감conda activate lerobot 후 다시 실행

      
conda은(는) ... 명령이 아닙니다일반 cmd/PowerShell 창을 사용시작 메뉴에서 Miniforge Prompt로 다시 열기

      
장치 관리자에 COM 포트가 안 보임USB 드라이버 없음, 충전 전용 케이블데이터용 케이블로 교체, 드라이버 설치

      
Could not connect on port포트 번호 틀림, 다른 프로그램이 포트 사용 중lerobot-find-port로 다시 확인, 아두이노 IDE 등 다른 프로그램 종료

      
Missing motor IDs전원 꺼짐, 3핀 케이블 빠짐, 모터 ID 미설정오류 아래 찾은 모터 목록을 확인. 비어 있으면 전원·포트·점퍼, 일부만 있으면 마지막으로 찾은 모터 다음 케이블, ID 1만 있으면 5단계 모터 ID 설정

      
모터 ID 설정에서 첫 모터(gripper)부터 못 찾음전원·점퍼·케이블 문제, 또는 컨트롤러 보드 고장전원 LED, B 채널 점퍼, 케이블 교체를 확인하고, 그래도 안 되면 다른 보드로 시험. 보드를 바꾸면 COM 번호 다시 확인

      
Waveshare 보드에서 통신이 안 됨보드 점퍼 위치점퍼 2개가 B 채널(USB)에 꽂혀 있는지 확인

      
캘리브레이션 때 이전 파일을 쓸지 물어봄같은 이름으로 이미 캘리브레이션함그대로 쓰려면 Enter, 다시 하려면 c 입력 후 Enter

      
캘리브레이션 표에 관절이 5개만 보임wrist_roll은 전체 범위를 자동으로 넣음빠진 것이 wrist_roll이면 정상, 그대로 진행

      
한 관절만 거의 안 움직이거나 덜 움직임캘리브레이션 때 그 관절을 끝까지 안 움직임그 팔의 캘리브레이션 다시 하기 (c 입력). 시뮬레이션으로 보기

      
팔로워암의 한 관절만 손으로 밀면 쉽게 밀림리더암용 모터(1/191, 1/147)가 팔로워암에 들어감모터 구분표로 스티커 확인, 1/345로 교체 후 ID 설정과 캘리브레이션 다시. 시뮬레이션으로 보기

      
팔로워암이 느리게, 딜레이가 있게 따라옴팔로워암에 5V 어댑터, 노트북 절전 모드, USB 허브12V로 교체, 노트북 충전기 연결 후 전원 모드 최고 성능, USB 본체에 직접 연결. 빠르게 휘두를 때 살짝 늦는 건 정상. 시뮬레이션으로 보기

      
모터가 갑자기 힘이 빠짐, 뜨거움과부하·과열 보호Ctrl + C로 종료, 전원을 뽑고 식힌 뒤 다시 켜기. 계속되면 혼 나사 풀림·기어 손상 확인

    
  

  

    
안전 수칙

    
    
      
  1. 로봇이 켜져 있는 동안 팔로워암 움직임 범위 안에 손이나 얼굴을 넣지 않아요.
    2. 
      
  2. 리더암은 천천히 움직여요. 갑자기 휘두르면 팔로워암도 갑자기 움직여요.
    3. 
      
  3. 관절이 끝에 닿았을 때 억지로 더 밀지 않아요.
    4. 
      
  4. 타는 냄새가 나거나 모터가 뜨거우면 즉시 Ctrl + C, 전원을 뽑고 선생님께 알려요.
    5. 
      
  5. 전원 어댑터는 각 팔에 정해진 것만 써요. (팔로워암 12V, 리더암 5V)
    6. 
      
  6. 사용 후에는 전원과 USB를 모두 뽑고 팔을 쉬는 자세로 정리해요.
    7. 
    

  







  

    

      Part 5
      
알아 두면 좋은 용어

      
설명서와 화면 메시지에 나오는 말들이에요.

    

  

  
로봇

  

    
리더암Leader
사람이 손으로 잡고 움직이는 팔. 조종기 역할이라 명령어에서는 teleop이라고 불러요.

    
팔로워암Follower
리더암을 따라 스스로 움직이는 실제 로봇. 명령어에서는 robot.

    
텔레오퍼레이션Teleoperation
멀리 떨어진 로봇을 사람이 실시간으로 조종하는 것. 리더-팔로워 연동이 바로 이거예요.

    
자유도DOF
로봇이 독립적으로 움직일 수 있는 방향의 개수. SO-101은 관절 5개 + 그리퍼 1개.

    
관절 이름
shoulder_pan 받침 회전 · shoulder_lift 어깨 · elbow_flex 팔꿈치 · wrist_flex 손목 굽힘 · wrist_roll 손목 회전 · gripper 집게

    
그리퍼Gripper
물건을 집는 집게. 리더암에서는 손가락으로 당기는 트리거가 그리퍼를 조종해요.

  

  
모터와 전기

  

    
서보 모터STS3215
정해진 각도로 돌아가 멈출 수 있는 모터. 안에 위치 센서와 제어 회로가 들어 있어요.

    
기어비1/345
모터 축이 345바퀴 돌 때 바깥 축이 1바퀴 도는 비율. 숫자가 클수록 힘이 세고 손으로 돌리기 뻑뻑해요.

    
토크Torque
돌리는 힘. 토크가 약하면 손으로 밀 때 쉽게 밀리고 무게를 못 버텨요.

    
모터 ID
한 줄에 이어진 모터들을 구분하는 번호(1~6). 모터 안에 저장돼요.

    
데이지 체인Daisy chain
모터를 꽃사슬처럼 줄줄이 잇는 연결 방식. 중간 케이블이 빠지면 그 뒤 모터를 모두 못 찾아요.

    
보드레이트Baudrate
신호를 주고받는 속도. 보드와 모터가 같아야 대화할 수 있어서 ID 설정 때 함께 맞춰요.

    
컨트롤러 보드Bus servo adapter
노트북의 USB 신호를 모터용 신호로 바꿔 주는 판. 팔마다 하나씩 있어요.

    
혼Horn
모터 축에 끼우는 둥근 판. 여기에 팔 부품을 나사로 고정해요. 풀리면 모터는 도는데 팔이 헛돌아요.

    
EEPROM
전원을 꺼도 지워지지 않는 모터 안 저장 공간. 모터 ID와 보드레이트가 여기 저장돼요.

  

  
컴퓨터와 LeRobot

  

    
LeRobot
허깅페이스가 만든 로봇 제어·학습 프로그램. 명령어가 모두 lerobot-로 시작해요.

    
가상환경conda env
프로그램끼리 섞이지 않게 만든 전용 작업 공간. 쓸 때마다 conda activate lerobot.

    
COM 포트
윈도우가 USB 장치에 붙이는 이름(COM3, COM4…). 꽂는 구멍이나 보드가 바뀌면 달라질 수 있어요.

    
드라이버CH340
윈도우가 보드를 알아보게 해 주는 프로그램. 없으면 장치 관리자에 노란 느낌표가 떠요.

    
캘리브레이션Calibration
관절의 가운데와 양 끝을 알려 주는 과정. 두 팔의 값을 같은 기준으로 맞춰요.

    
MIN / POS / MAX
캘리브레이션 표의 최솟값 / 현재 위치 / 최댓값. 모터 한 바퀴를 0~4095로 나눈 숫자예요.

    
정규화 값-100 ~ 100
캘리브레이션한 범위를 -100(한쪽 끝)~100(반대쪽 끝)으로 바꾼 값. 그리퍼는 0(닫힘)~100(열림).

    
id (이름)
캘리브레이션 파일을 구분하는 팔 이름. 같은 이름을 써야 저장된 값을 다시 불러와요.

    
Ctrl + C
Prompt 창에서 실행 중인 프로그램을 멈추는 단축키.

  







  

    

      Part 6
      
다음 도전

      
연동이 되면 SO-101로 할 수 있는 다음 활동이에요. 필요한 준비물을 미리 챙겨 두면 좋아요.

    

  

  

    
카메라 붙이기
USB 웹캠을 팔로워암 앞이나 손목에 달면 로봇이 보는 장면을 함께 기록할 수 있어요. 카메라 번호는 lerobot-find-cameras opencv로 찾아요.

    
시연 데이터 모으기
리더암으로 같은 동작(예: 블록 옮기기)을 수십 번 보여 주고 lerobot-record로 기록해요. 허깅페이스 계정이 있으면 데이터를 올려 공유할 수 있어요.

    
AI로 스스로 움직이기
모은 데이터로 ACT 같은 모방학습 모델을 학습시키면 리더암 없이 팔로워암이 동작을 따라 해요. 학습에는 NVIDIA 그래픽카드가 있는 PC나 구글 Colab이 필요해요.
