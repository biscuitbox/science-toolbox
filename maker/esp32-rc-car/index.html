ESP32 TT모터 RC카 만들기

노란 TT모터 4개로 달리는 무선 RC카와 조이스틱 조종기를 만들어요. 3D 모델을 돌려 보며 단계별로 조립하고, 코드를 올린 뒤 조종기·스마트폰으로 운전해요. 초음파·라인센서·카메라를 더 달 수도 있어요.

RC카가 움직이는 원리

조종기와 차에 ESP32가 하나씩 들어 있어요. 둘은 와이파이 칩으로 공유기 없이 직접 신호를 주고받아요(ESP-NOW). 1초에 50번 스틱 값을 보내고, 0.5초 동안 신호가 없으면 차는 스스로 멈춰요.

1 · 읽기조종기 ESP32가 조이스틱의 가변저항 전압(0~3.3V)을 0~4095 숫자로 읽어요.
2 · 보내기전진 값과 방향 값을 −255~255로 바꿔 ESP-NOW로 방송해요. 같은 CAR_ID 차만 받아요.
3 · 계산하기차 ESP32가 왼쪽 = 전진+방향, 오른쪽 = 전진−방향으로 바퀴 속도를 정해요(탱크식 조향).
4 · 돌리기L298N이 ESP32의 약한 신호(PWM)를 받아 배터리의 큰 전류로 모터를 돌려요.

먼저 하판 하나만 출력해 보세요

  1. TT모터는 회사마다 볼트 구멍 위치가 조금씩 달라요. 하판을 먼저 뽑아 모터를 대 보고, 볼트가 들어가는지 확인해요.
  2. 모터 볼트 자리는 앞뒤로 ±3mm 긴 구멍이라 조금 달라도 맞출 수 있어요.
  3. 너무 많이 다르면 cad/params.py의 TT_HOLE_D1·TT_HOLE_D2(축 중심에서 구멍까지 거리)를 재서 고친 뒤 python build_all.py로 다시 만들어요.
  4. 반 전체가 만들 때는 하판·상판(4~5시간)을 미리 출력해 두고, 작은 부품은 수업 중에 출력하면 시간이 맞아요.

5코드 올리기

컴퓨터에 아두이노 IDE를 설치하고, 차 ESP32에는 rc_car, 조종기 ESP32에는 rc_controller를 올려요. 따로 설치할 라이브러리는 없어요. 그림은 아두이노 IDE 2 화면을 단순하게 그린 예시예요.

아두이노 IDE 설치하고 ESP32 보드 추가하기

  1. arduino.cc/en/software에서 Arduino IDE 2를 받아 설치해요.
  2. 파일 → 기본 설정을 열고 추가 보드 관리자 URL 칸에 아래 주소를 붙여 넣고 확인을 눌러요.
https://espressif.github.io/arduino-esp32/package_esp32_index.json
  1. 왼쪽 두 번째 아이콘(보드 매니저)을 누르고 esp32를 검색해요.
  2. esp32 by Espressif Systems의 설치를 눌러요. 처음 한 번만 하면 되고 5~10분 걸려요.

USB 드라이버 확인하기

ESP32를 USB 데이터 케이블로 컴퓨터에 꽂아요. 보드의 USB 옆 칩 글자를 보고 필요하면 드라이버를 설치해요.

  • CP2102 (네모난 칩, CP210x): Silicon Labs CP210x 드라이버
  • CH340 / CH9102: WCH CH341SER 드라이버
포트가 안 보이면 · 충전 전용 케이블이 아닌지 먼저 확인하세요. 학생들이 가장 많이 막히는 곳이에요. 데이터 케이블에 색 테이프로 표시해 두면 좋아요.

코드 열고 우리 팀 번호 정하기

  1. 받은 zip을 풀고 code/rc_car/rc_car.ino를 더블클릭해 열어요. 폴더 이름과 파일 이름이 같아야 열려요.
  2. 위쪽 탭에서 config.h를 눌러요.
  3. #define CAR_ID 1의 숫자를 선생님이 정해 준 팀 번호로 바꿔요. 조종기 코드의 CAR_ID도 같은 번호여야 해요.
  4. WIFI_CHANNEL도 정해 준 채널로 바꿔요 (차와 조종기가 같게).
  5. 센서를 안 달았으면 그 줄의 1을 0으로 바꿔요. 예: 초음파가 없으면 USE_ULTRASONIC 0.

보드와 포트 고르기

  1. 위쪽 보드 선택 칸을 누르고 다른 보드와 포트 선택을 눌러요.
  2. 보드에 ESP32 Dev Module을 검색해 고르고, 포트는 USB를 꽂을 때 새로 생기는 COM 번호(맥은 /dev/cu.usbserial…)를 골라요.
  3. 어떤 포트인지 모르겠으면 USB를 뺐다 꽂아 보고 사라졌다 생기는 것을 골라요.
업로드가 자꾸 실패하면 · 도구 → Upload Speed를 115200으로 낮춰 보세요.

업로드하기

  1. 오른쪽 화살표(→) 업로드 버튼을 눌러요. 처음에는 컴파일에 1~2분 걸려요.
  2. 아래 출력 창에 Connecting........이 나오면 BOOT 버튼을 누르고 있다가 Writing at…이 보이면 떼요. 보드에 따라 안 눌러도 될 때가 있어요.
  3. Hard resetting via RTS pin…이 나오면 끝이에요. EN 버튼을 한 번 눌러 다시 시작해요.
주의 · 업로드할 때는 차의 전원 스위치를 꺼 두세요. USB와 배터리를 동시에 연결하면 바퀴가 갑자기 돌 수 있어요.

시리얼 모니터로 확인하기

  1. 오른쪽 위 돋보기 모양 시리얼 모니터를 열고 속도를 115200 baud로 맞춰요.
  2. EN 버튼을 누르면 RC카 준비 완료 CAR_ID=3처럼 나와요. 팀 번호가 맞는지 확인해요.
  3. 조종기도 같은 방법으로 code/rc_controller를 올려요. 조종기를 켜면 차 쪽 모니터에 [LINK] 조종기 연결됨이 나와요.
글자가 깨져 보이면 · 모니터 속도가 115200인지 확인하세요.

ESP32-CAM 올리기 (카메라를 달 때만)

  1. ESP32-CAM을 ESP32-CAM-MB(USB 보드)에 핀 방향을 맞춰 꽂고 USB로 연결해요.
  2. 보드는 AI Thinker ESP32-CAM, 도구 → PSRAM은 Enabled.
  3. code/rc_cam/config.h의 CAR_ID를 차와 같게 하고 업로드해요.
  4. Connecting…에서 멈추면 MB 보드의 IO0 버튼을 누른 채 RST를 한 번 눌렀다 떼요.
  5. 업로드가 끝나면 RST를 눌러요. 시리얼 모니터에 [CAM] 연결 480x320 15.0 fps가 나오면 성공이에요.

스마트폰 조종 화면을 고치고 싶을 때

조종 화면은 code/rc_car/web/index.html이 원본이에요. 고친 뒤 python web/make_webapp_h.py를 실행하면 webapp.h가 새로 만들어지고, 다시 업로드하면 반영돼요. 컴퓨터 브라우저로 index.html을 열면 미리보기 화면이 보여요.

6첫 시험 · 충전

처음 전원을 넣을 때는 차를 상자나 컵 위에 올려 바퀴가 바닥에 닿지 않게 해요.

순서

  1. 스위치 OFF 상태에서 멀티미터로 L298N 12V와 GND 사이가 0Ω(합선)이 아닌지 확인해요.
  2. 처음에는 스위치를 끈 채로 USB-C로 배터리를 가득 충전해요(아래 ‘충전하기’). 그다음 스위치를 켜요. ESP32 파란 LED가 깜빡이면 조종기를 기다리는 중이에요.
  3. 조종기를 스틱에서 손을 뗀 채로 켜요(가운데 값 자동 맞춤). 부저가 두 번 울리고 조종기 LED가 켜지면 연결됐어요.
  4. 왼쪽 스틱을 살짝 위로 밀어 네 바퀴가 모두 앞으로 도는지 봐요.
  5. 오른쪽 스틱을 오른쪽으로 밀면 왼쪽 바퀴는 앞으로, 오른쪽 바퀴는 뒤로 돌아야 해요.
  6. 조종기를 끄면 0.5초 안에 바퀴가 멈추는지 확인해요(안전 정지).
  7. 손을 초음파 센서 앞 10cm에 대고 전진하면 멈추고 부저가 울려야 해요.
  8. 시리얼 모니터의 [BATT] 8.12V 값과 멀티미터로 잰 배터리 전압을 비교해요. 0.1V 넘게 다르면 BATTERY_CAL = 멀티미터 값 ÷ 모니터 값으로 고쳐요.
이렇게 되면이렇게 고쳐요

충전하기

  1. 차의 전원 스위치를 끄고, 차 뒤쪽 USB-C 구멍에 충전기를 꽂아요. 상판을 열 필요가 없어요.
  2. 충전 모듈의 표시등이 켜져요. 표시 방법은 제품마다 달라요(대부분 충전 중 깜빡임 → 완료 켜짐, 또는 빨강 → 초록).
  3. 5V 2A 충전기로 약 2~3시간, PD 충전기를 쓰면 더 빨라요. 다 차면 약 8.4V예요.
  4. 달리다가 폰 화면에 ‘충전 필요’가 뜨거나 조종기 LED가 두 번씩 깜빡이면 충전할 때예요.
  5. 더 낮아지면 차가 스스로 멈추고 부저가 6번 울려요(배터리 보호). 스위치를 끄고 충전하면 돼요.

7스마트폰 조종 · 카메라

차 ESP32가 직접 와이파이를 열고 조종 화면을 보내 줘요. 앱 설치나 인터넷 없이 폰 브라우저만 있으면 돼요(아이폰·안드로이드).

폰으로 조종하기

  1. 차를 켜면 와이파이 RC-CAR-팀번호(비밀번호 12345678)가 생겨요.
  2. 폰에서 연결하면 조종 화면이 자동으로 떠요. 안 뜨면 브라우저 주소창에 192.168.4.1.
  3. 폰을 가로로 들고, 화면 아무 곳에 엄지를 대면 원형 조이스틱이 나타나요. 왼쪽 엄지는 전진·후진, 오른쪽 엄지는 방향.
  4. 톱니바퀴에서 스틱 1개(한 손), 좌우 바꾸기(왼손잡이)를 고를 수 있어요.
  5. 조종기와 폰을 같이 켜 두면, 운전하던 쪽이 1초 동안 스틱을 놓을 때 다른 쪽이 넘겨받아요.
아이폰 · 연결 후 뜨는 작은 창에서 바로 조종해도 되고, "취소 → 인터넷 연결 없이 사용"을 고른 뒤 사파리에서 192.168.4.1로 들어가도 돼요. 안드로이드 · "인터넷 없음" 알림이 뜨면 "연결 유지".

카메라로 실시간 화면 보기 (선택)

  1. 9단계처럼 상판 맨 앞에 카메라 받침과 홀더를 달고, ESP32-CAM 뒷면을 폼테이프로 붙여요.
  2. 카메라 전원은 5V 강압 모듈로 따로 줘요. 강압 모듈 출력을 멀티미터로 5.0V에 맞춘 뒤 ESP32-CAM 5V·GND에 연결해요.
  3. ESP32-CAM 코드를 올리면 차 와이파이에 스스로 접속해요(뒷면 빨간 LED가 켜짐).
  4. 폰 조종 화면 뒤에 영상이 꽉 차게 깔려요. 위쪽 카메라 버튼으로 켜고 끄고, 톱니바퀴에서 화질·위아래 뒤집기를 바꿔요.
  5. 전조등 버튼을 누르면 카메라 플래시도 함께 켜져요.
주의 · L298N의 5V로 ESP32와 카메라를 함께 돌리면 전류가 모자라 재부팅돼요. 영상은 한 번에 폰 1대만 볼 수 있어요.

9안전 수칙

리튬 배터리는 작지만 에너지가 커요. 아래 내용은 만들기 전에 함께 읽어요.

보호회로 팩과 2S 충전 모듈만 쓰기보호회로가 들어 있는 18650 2S 팩과 8.4V용 2S 충전 모듈을 써요. 찌그러지거나 비닐이 벗겨진 팩은 쓰지 않아요.
+와 −를 절대 맞대지 않기팩의 빨강·검정 선 끝이 서로 닿거나 쇠붙이에 닿으면 순식간에 뜨거워져요. 납땜 전까지 선 끝은 절연 테이프로 감아 두어요.
극성 두 번 확인충전 모듈 B+·B−와 L298N 12V·GND에 빨강·검정이 맞는지 확인한 뒤 스위치를 켜요.
충전은 스위치 OFF, 지켜보는 곳에서스위치를 끈 채로, 사람이 있는 곳에서 충전하고 다 되면 뽑아요. 뜨거워지거나 냄새가 나면 바로 빼요.
납땜은 선생님과 함께인두 끝은 350℃ 이상이에요. 인두 받침에 두고, 환기하고, 납땜 후에는 손을 씻어요.
바퀴 띄우고 시험처음 시험과 코드 수정 후에는 바퀴를 띄운 채 확인하고, 사람 발 쪽으로 달리지 않아요.
L298N 방열판은 뜨거워요오래 달린 뒤에는 방열판을 만지지 말고 식혀요.
다 쓰면 스위치 OFF쓰지 않을 때는 스위치를 꺼요. 오래 보관할 때는 절반 정도(약 7.6V) 충전해 두어요.

알아 두면 좋은 용어

조립과 코드 설명에 나오는 말들이에요.

ESP32microcontroller
와이파이와 블루투스가 들어 있는 작은 컴퓨터 칩. 차와 조종기에 하나씩 들어가요.
ESP-NOWwireless
공유기 없이 ESP32끼리 바로 짧은 신호를 주고받는 방법. 빠르고 연결이 간단해요.
모터 드라이버L298N
ESP32의 약한 신호로 모터에 큰 전류를 흘려 주는 장치. 방향과 속도를 바꿔요.
H-브리지H-bridge
스위치 4개로 모터에 흐르는 전류 방향을 바꿔 앞뒤로 돌리는 회로. IN1·IN2로 고르고요.
PWMpulse width modulation
전기를 아주 빠르게 켰다 껐다 하며, 켜진 시간의 비율로 모터 속도를 조절하는 방법이에요.
탱크식 조향differential drive
앞바퀴를 꺾지 않고 왼쪽·오른쪽 바퀴 속도를 다르게 해서 방향을 바꾸는 방식이에요.
조이스틱KY-023
가변저항 2개로 스틱 위치를 전압으로 바꾸는 부품. 누르면 버튼도 돼요.
ADCanalog → digital
전압을 숫자로 바꾸는 장치. ESP32는 0~3.3V를 0~4095로 읽어요.
데드존dead zone
스틱이 가운데 근처에서 살짝 흔들려도 0으로 보는 범위예요.
페일세이프failsafe
신호가 끊기는 등 문제가 생기면 자동으로 안전한 상태(정지)로 가는 설계예요.
초음파 센서HC-SR04
초음파를 쏘고 돌아오는 시간을 재서 거리를 구해요. 거리(cm) = 시간(µs) ÷ 58.
전압 분배voltage divider
저항 두 개로 전압을 나눠 낮추는 방법. 5V ECHO 신호를 3.3V로 낮춰 ESP32를 보호해요.
승압 · 강압boost · buck
전압을 올리거나(MT3608) 내리는(MP1584) 모듈. 출력은 가변저항으로 맞춰요.
GND 공통common ground
여러 모듈의 GND를 하나로 이어야 신호의 기준 전압이 같아져요. 안 이으면 오작동해요.
18650Li-ion cell
지름 18mm, 길이 65mm 리튬이온 배터리. 1개 3.7V, 가득 차면 4.2V예요.
2S 팩 · 보호회로2S · PCM
셀 2개를 직렬로 이은 7.4V 팩. 보호회로가 과충전·과방전·합선을 막아요.
장공slot hole
길쭉한 구멍. 볼트 위치가 조금 달라도 맞출 수 있게 해요.
캡티브 포털captive portal
와이파이에 연결하면 웹페이지가 자동으로 뜨게 하는 방식. 폰 조종 화면이 이렇게 떠요.
MJPEGmotion JPEG
사진(JPEG)을 빠르게 이어서 보내는 영상 방식. ESP32-CAM이 이렇게 보내요.
