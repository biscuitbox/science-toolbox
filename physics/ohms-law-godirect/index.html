물리 중2~중3실험

전압·전류 센서 실시간 그래프

무선 전압 센서와 전류 센서(Vernier Go Direct)를 웹 페이지에 바로 연결해, 니크롬선에 걸린 전압과 흐르는 전류를 전압–전류 그래프로 실시간 기록합니다.

교사용 정보 성취기준 [9과14-02], 준비할 것, 지원 기기, 수업 흐름

[9과14-02] 전기 회로에서 전류를 모형으로 설명하고, 실험을 통해 저항, 전류, 전압 사이의 관계를 이끌어낼 수 있다. — 교육과정의 "디지털 탐구 도구를 활용할 수 있다"에 맞춰 실물 센서 값으로 그래프를 그립니다.

  • 필요한 것 — Go Direct 전압 센서(GDX-VOLT) 1개, Go Direct 전류 센서(GDX-CUR) 1개, 전원 장치, 길이가 다른 니크롬선 2개, 집게 전선. 센서는 미리 충전해 둡니다.
  • 지원 기기 — 크롬·엣지 브라우저가 있는 윈도우 노트북, 크롬북, 맥, 안드로이드 태블릿. 블루투스(무선) 또는 USB 케이블(윈도우·맥·크롬북)로 연결합니다. 아이패드·아이폰은 웹 블루투스를 지원하지 않아 이 페이지로는 연결할 수 없습니다(그때는 Vernier Graphical Analysis 앱 사용).
  • 반드시 인터넷 주소(https)로 열기 — GitHub Pages 주소로 열어야 센서 연결이 됩니다. 파일을 내려받아 더블클릭으로 열면 브라우저가 연결을 막습니다.
  • 센서 범위 — 전류 센서 ±1 A(최대 견딤 1.5 A), 전압 센서 ±20 V. 6 V에서 1 A를 넘지 않도록 니크롬선 저항이 6 Ω 이상인지 확인합니다. 1 A에 가까워지면 화면에 경고가 나옵니다.
  • 수업 흐름 — 모둠마다 기기 1대: ③ 연결 도움말대로 회로 꾸미기 → 전원 장치 0 V에서 두 센서 「영점 맞추기」 → 「긴 니크롬선」을 고르고 기록 시작 → 전압을 천천히 6 V까지 → 0 V로 낮추고 짧은 니크롬선으로 바꿔 반복 → ② 결과 분석.
  • 연습 모드 — 센서가 없어도 「연습 모드」로 같은 화면을 미리 써 볼 수 있습니다(가상 측정값). 수업 전 교사 연습이나 센서가 부족한 모둠용으로 쓰세요. 같은 내용의 「전류, 전압, 저항 사이의 관계 가상실험」 도구도 있습니다.

전압–전류 그래프

이 기기에서 쓸 수 있나요?

    연결 방법

    전압 센서 ○ 연결 안 됨

    GDX-VOLT — 니크롬선 양 끝에 병렬로

    전류 센서 ○ 연결 안 됨

    GDX-CUR — 회로에 직렬로

    지금 기록할 니크롬선

    기록 방법

    센서가 없나요? 연습 모드로 화면을 미리 써 볼 수 있어요.

    · 0.00 V

    ⚠️
    안전 수칙
    • 전원을 켜거나 끌 때, 니크롬선을 바꿀 때는 전압 조절 손잡이를 0으로.
    • 니크롬선은 뜨거워지니 맨손으로 만지지 않아요. 측정이 끝나면 바로 0 V로.
    • 전류 센서는 1 A를 넘기지 않아요.
    결과 그래프

    ① 연결·측정에서 기록하면 여기에 표와 그래프가 만들어져요.

    결과 정리 — 내 생각을 먼저 적어야 예시 답을 볼 수 있어요

    회로 꾸미기

    1. 전류 센서는 직렬로 — 전원 장치 (+) → 전류 센서 빨간 집게, 전류 센서 검은 집게 → 니크롬선 한쪽 끝, 니크롬선 다른 끝 → 전원 장치 (−).
    2. 전압 센서는 병렬로 — 빨간 집게를 니크롬선의 (+)쪽 끝, 검은 집게를 (−)쪽 끝에 물립니다.
    3. 전원 장치의 전압 조절 손잡이를 0으로 두고 전원을 켭니다.

    센서 연결하기

    1. 센서의 전원 버튼을 눌러 켭니다. 블루투스 표시등이 빨갛게 깜박이면 연결 준비 완료.
    2. ① 화면에서 연결 방법(블루투스 / USB)을 고르고, 전압 센서 칸의 연결하기를 누릅니다.
    3. 브라우저 창에 뜬 목록에서 GDX-VOLT로 시작하는 이름을 골라 「페어링」 또는 「연결」을 누릅니다. 여러 모둠이 함께 쓰면 센서 몸통에 적힌 일련번호와 목록의 번호를 맞춰 보세요.
    4. 전류 센서도 같은 방법으로 GDX-CUR를 연결합니다. (센서를 바꿔 골라도 알아서 제 칸으로 옮겨 줍니다.)
    5. 전원 장치가 0 V인 상태에서 두 센서의 영점 맞추기를 누릅니다.
    6. 니크롬선을 고르고 기록 시작 → 손잡이를 천천히 돌려 6 V까지 → 0 V로 낮추고 니크롬선을 바꿔 반복합니다.

    연결이 안 될 때

    • 목록에 센서가 안 보여요 — 센서 전원이 켜졌는지, 다른 기기(태블릿 앱 등)에 이미 연결되어 있지 않은지 확인. 기기의 블루투스도 켜져 있어야 해요.
    • 연결하기 버튼이 반응이 없어요 — 크롬 또는 엣지인지, 주소가 https로 시작하는지 확인. 학교 관리 기기는 블루투스 웹 연결이 막혀 있을 수 있으니 USB 케이블로 바꿔 보세요.
    • 값이 음수(−)예요 — 빨간·검은 집게가 반대로 꽂혀 있어요. 바꿔 꽂으세요.
    • 전압이 0인데 전류가 조금 나와요 — 전원 장치를 0 V로 두고 「영점 맞추기」를 누르세요.
    • 중간에 끊겼어요 — 센서 배터리를 확인하고 「다시 연결」을 누르세요. 이미 기록한 점은 그대로 남아 있어요.
